# design-system

Design System do Criativo Dodô — `index.html` (versão navegável) e `../DESIGN.md` (versão
longa e citável) são o mesmo conteúdo em dois formatos, mantidos juntos.

Origem: auditoria direta do código real em produção — `app/src` (Landing) e
`portal-frontend/src` (Portal) — não de um documento anterior nem de referência externa.
Referências externas (Herman Miller Brand Standards, Spotify Design Guidelines, Hulu, GitHub)
influenciaram só a arquitetura de navegação deste site, nunca a identidade visual.

Não editar `index.html` sem checar o valor correspondente contra o código primeiro — ver
"Governança do documento" em `DESIGN.md` §32.

Última auditoria: 28 de julho de 2026, v2.0.
