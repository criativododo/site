# DECISIONS

> Registro permanente das decisões que moldam a linguagem de design do Criativo DODÔ.
>
> Este documento registra apenas decisões estruturais.
> Mudanças de implementação pertencem ao código, ao CSS ou ao Design System.
>
> Uma decisão aprovada nunca é editada.
> Se ela deixar de valer, uma nova decisão a substitui.

---

# Quando registrar uma decisão

Uma decisão entra neste documento apenas quando altera permanentemente a forma como o DODÔ pensa, projeta ou comunica.

Exemplos:

- mudança de filosofia;
- mudança de direção visual;
- novas restrições permanentes;
- princípios aprovados;
- mudanças na arquitetura da Design Language.

Não registrar:

- ajustes visuais;
- componentes;
- tokens;
- CSS;
- espaçamentos;
- cores específicas;
- detalhes de implementação.

---

# Status

Cada decisão possui um único status.

| Status | Significado |
|---------|-------------|
| Proposed | Em discussão |
| Active | Regra oficial |
| Superseded | Substituída por outra decisão |

# Regras permanentes

Nunca apagar uma decisão.

Nunca editar uma decisão ativa.

Quando uma decisão mudar:

1. criar um novo registro;
2. marcar o anterior como **Superseded**;
3. referenciar o novo ID.

O objetivo deste documento não é contar a história do projeto.

É preservar o motivo das decisões.
