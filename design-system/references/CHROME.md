# Chrome

## Papel desta referência

O chrome é a moldura da experiência.

Ele reúne todos os elementos persistentes que orientam, contextualizam e permitem a interação com o conteúdo.

O chrome nunca é o protagonista.

Ele existe para servir ao conteúdo.

---

# A Lei da Subordinação

No Criativo DODÔ, a moldura sempre serve ao conteúdo.

Nunca o contrário.

---

# Filtro universal

Antes de adicionar qualquer elemento permanente à interface, pergunte:

- Ajuda o usuário a se orientar?
- Ajuda o usuário a agir?
- Reduz a carga cognitiva?
- O conteúdo continua sendo o protagonista?
- Poderíamos remover este elemento sem prejudicar a experiência?

Se qualquer resposta for "não", descarte a ideia.

---

# Função do chrome

O chrome existe para responder silenciosamente:

- Onde estou?
- O que estou vendo?
- O que posso fazer agora?
- Como volto?
- Qual é o próximo passo?

Se não responder essas perguntas, provavelmente não pertence ao chrome.

---

# Princípios que adotamos

## 1. O conteúdo é o protagonista

A maior parte da atenção visual deve pertencer ao conteúdo.

O chrome apenas o sustenta.

---

## 2. Clareza antes da decoração

A navegação deve ser imediatamente compreendida.

Nunca estilizada em excesso.

---

## 3. Proporção de valor

A moldura ocupa apenas o espaço necessário.

O restante pertence ao conteúdo.

---

## 4. Consistência espacial

Os elementos permanentes permanecem previsíveis.

O usuário nunca deve reaprender a navegar.

---

## 5. Revelação progressiva

Ferramentas secundárias aparecem somente quando o contexto exige.

A interface nunca apresenta toda a complexidade de uma só vez.

---

## 6. Movimento funcional

O chrome pode reduzir presença ou desaparecer quando o usuário entra em modo de leitura ou consumo.

Movimento existe para explicar.

Nunca para impressionar.

---

## 7. Neutralidade visual

O chrome utiliza cor, contraste e materiais de forma discreta.

A identidade visual pertence principalmente ao conteúdo.

---

# Tradução para o DODÔ

No Criativo DODÔ isso significa:

- o projeto é o protagonista;
- o chrome é silencioso;
- o header é leve;
- a navegação é previsível;
- o espaço negativo substitui divisórias sempre que possível;
- o Cherry nunca constrói a navegação;
- o Ô. aparece apenas quando reforça orientação, nunca como decoração.

---

# Zona de exclusão

Nunca utilizar:

- branding excessivo na navegação;
- barras chamativas;
- headers desproporcionais;
- excesso de controles permanentes;
- molduras pesadas;
- cores vibrantes como fundo estrutural;
- menus que competem com o conteúdo;
- hierarquia invertida entre chrome e conteúdo.

---

# Resumo

O chrome existe para orientar.

Quando a moldura chama mais atenção que o conteúdo, ela falhou.

Quando o usuário esquece que ela existe, ela cumpriu seu papel.
