# Rebranding Toolkit

## Scripts

- migrate-brand.sh
  Executa a migração automática.

- validate-brand.sh
  Valida referências restantes.

- rollback-brand.sh
  Reverte alterações usando Git.

- helpers.sh
  Funções compartilhadas.

Fluxo recomendado:

1. migrate-brand.sh
2. validate-brand.sh
3. Testes
4. rollback-brand.sh (se necessário)
