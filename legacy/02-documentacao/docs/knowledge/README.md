# docs/knowledge/

Conhecimento de apoio ao desenvolvimento — não é a fonte oficial de estado
do projeto (essa é `docs/_workspace/TASK_ROUTER.md`, ver `CLAUDE.md`) nem
substitui ADR (`docs/adrs/`) para decisões de arquitetura.

## Estrutura

- **`sistema-b/`** — `ARCHITECTURE.md`, `DOMAIN_MODEL.md`,
  `BUSINESS_FLOWS.md`: arquitetura, modelo de domínio e fluxos de negócio
  do `tear-v2-app` (Laravel + React).
- **`referencias-externas/`** — `REFERENCIAS_ARQUITETURAIS.md`: panorama de
  projetos open source com funcionalidades análogas às do Influencia,
  organizado por domínio (CRM, workflow, contratos, upload, notificações,
  portais, dashboards etc.), para consulta antes de desenhar um módulo
  novo ou justificar uma escolha de arquitetura em ADR.
